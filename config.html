说明：同步到微软日历前，需要先在 Microsoft Entra 应用注册里创建一个“公共客户端/桌面应用”，并授予 Calendars.ReadWrite 与 User.Read 委托权限。如果你要同步到其他组织或个人 Microsoft 账号，应用注册的“支持的帐户类型”必须改成多租户，个人账号场景还要允许“个人 Microsoft 帐户”。
